# Working in competitiontoolbox

Routine implementation may be performed directly on `master`, the maintained default branch. The `refactor` migration is integrated; do not recreate that branch. Start any necessary isolated task branch from `master`.

Preserve uncommitted local changes and unrelated branches or worktrees.

The application routes economic calculations through antitrust, trade, and vertical public APIs; keep UI routes aligned with implemented upstream registries.

Test economic behavior and cross-package integration where relevant. Run proportionate checks and report what actually ran; distinguish ordinary checks from extended statistical validation.
